# Portfolio - Jibril Khattaf Mendil

Portfolio personnel (BTS SIO option SLAM) publie en statique.

## Contenu
- Presentation et objectif professionnel
- Competences techniques et soft skills
- Projets representatifs
- Stages (1re et 2e annee)
- Veille technologique
- CV et contact

## Stack
- HTML
- CSS
- JavaScript

## Lancement local
1. Cloner le depot.
2. Ouvrir `index.html` dans un navigateur.

## Mise en ligne (GitHub Pages)
1. Pousser le code sur `main` du depot `PORTEFOLIO_JIBRIL`.
2. Ouvrir le depot GitHub.
3. Aller dans `Settings` > `Pages`.
4. Dans `Build and deployment`, choisir `Deploy from a branch`.
5. Selectionner `main` et dossier `/ (root)`, puis `Save`.
6. Attendre 1 a 3 minutes.
7. Ouvrir l'URL publiee:
   `https://jibril-km.github.io/PORTEFOLIO_JIBRIL/`

## Fichiers web ajoutes
- `robots.txt` pour l'indexation.
- `sitemap.xml` pour les moteurs de recherche.
- `manifest.webmanifest` pour l'installation web.
- `.nojekyll` pour la compatibilite GitHub Pages.
- `assets/og-preview.svg` et `assets/favicon.svg` pour le partage et l'icone.
